Política de Privacidade do Atrium

Última atualização: 2 de novembro de 2026.

Quem usa

O Atrium é um sistema pessoal, usado apenas pelo seu autor. Ninguém mais tem conta nele.

O que é acessado no Gmail

Com a permissão gmail.readonly, o Atrium lê somente os e-mails de remetentes cadastrados pelo próprio usuário: extratos enviados pelos bancos e mensagens de plataformas de vagas. O Atrium nunca envia, apaga, move ou marca e-mails.

Como os dados são usados

  • O anexo do extrato é lido para sugerir lançamentos financeiros, que só são gravados depois da revisão do usuário.
  • O texto da mensagem de vaga é enviado à API do Google Gemini para identificar empresa, vaga e resultado, e virar uma sugestão de atualização da candidatura.

Armazenamento e compartilhamento

  • O token de acesso ao Gmail é guardado cifrado. O conteúdo dos e-mails não é registrado em log.
  • Os dados não são vendidos, não são usados para publicidade e não são compartilhados com terceiros, exceto o envio ao Google Gemini descrito acima.

Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar

O acesso pode ser removido a qualquer momento no próprio Atrium ou em myaccount.google.com/connections. Ao desconectar, o token é revogado e apagado.
